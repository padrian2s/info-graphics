The mobile web parallel

history rhymes

In 2007, the web already existed. It worked on phones — technically. But it was designed for desktops. What followed was a decade-long rebuild: responsive design, app stores, push notifications, tap-to-pay. The underlying infrastructure was the same, but the interface layer forked completely.

The companies that recognized the fork early — that built for the new client instead of making the old interface work — built Uber, Instagram, WhatsApp, Snap. Trillion-dollar companies that could not have existed on the desktop web.

The trust gap

central tension
Humans want: 70% control
Infrastructure assumes: 0% human

The infrastructure being built right now assumes fully autonomous agents with their own wallets, search, execution environments, and economic relationships. The gap between what's being built and the trust people are willing to extend is the central tension of the next few years.

The correct mental model

consensus

Treat the agent as a potential adversary, not a trusted employee.
Every serious security approach — IronClaw's WASM sandboxing, OpenAI's container isolation, Coinbase's enclave key storage — assumes the agent itself cannot be fully trusted with the assets it manages.

IronClaw (near.ai)

Rust-based OpenClaw reimplementation. Every tool sandboxed into isolated WebAssembly. Assumption: any tool is a compromise vector.

OpenAI Shell Tool

Org-level network allow lists, domain secrets, container isolation. Assumption: agents will run untrusted code, blast radius must be contained.

Coinbase Agentic Wallets

Enclave isolation for private keys. Programmable spending guardrails. Assumption: agent cannot be trusted with the assets it manages.

The emergent web (it's already happening)

chaining capabilities

A developer connected OpenClaw to a video generation model. He sent it an Amazon product link. The agent: crawled the page, extracted product info, identified suitable assets, fed them into a video model, and produced a UGC-style product video. The kind of content brands pay creators $1,000 to produce. No human touched any step.

Why this pattern is inevitable

None of these services were designed to work together. The Amazon page wasn't built for agents. The video model wasn't designed to receive input from crawlers. But because each piece exposes capabilities through APIs and structured data, the agent stitches them into workflows no individual company planned. When primitives exist and agents are smart enough, integration is emergent.

Stripe's fraud detection problem

the old world is broken
Old signals (now useless)dead

Mouse movement variability. Browsing time. Session behavior. Device fingerprinting. Decades of fraud ML calibrated for human shopping — all of it meaningless when the buyer is software.

New realityrebuild

Stripe had to retrain Radar from scratch. They built an entirely new fraud model for a client that is, by any prior definition, a bot. And yet bots are now legitimate purchasers. Urban, Etsy, Coach, Kate Spade already onboarding.

What to build for

strategic implications
If you own infrastructurebuild primitives

Your design decisions become de facto web standards. The companies doing this — Coinbase, Stripe, Cloudflare — have the scale and distribution to make their choices stick. This is the TCP/IP layer of the agent economy. Capture it and everything flows through you.

If you build productsserve two clients

Your website now has two audiences: humans who want beautiful pages, and agents who want JSON payloads with price, availability, and payment endpoints. Ship llm.txt. Expose structured APIs. Accept tokenized payments. The businesses that emerge from this fork couldn't have existed on the human web alone.

If you make contentrepeatable patterns collapse

A $1,000 UGC video from a single link, at near-zero cost. Product descriptions, social posts, email campaigns, comparison articles — every content type that follows a repeatable pattern is getting compressed to commodity pricing. Your moat is taste, judgment, and brand trust that agents can't replicate.

The real scam vs the real signal

TikTok is flooded with "$50 to $3,000 in days" AI trading claims. Reality: the famous bot that turned $313 into $438K was running latency arbitrage requiring colocated infrastructure with sub-10ms latency. One developer spent $200 in API fees in two days. But the underlying premise — agents participating in economic activity — is exactly where billions in infrastructure investment are going.

The primitive of trust

Every company in the agent stack is betting that trust will catch up to capability. Every security incident — OpenClaw's remote code execution, the iMessage disaster, Redis databases wiped by unsupervised agents — pushes the trust timeline back. Without the base layer of trust, the agent web may be stillborn. Trust is the primitive nobody has shipped yet.
